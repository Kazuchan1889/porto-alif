# Muhammad Alif Ramadhani - Portfolio Website

A modern, high-aesthetic responsive developer portfolio website built with **React (JSX)**, **Tailwind CSS**, and **Vite**, deployable on **Vercel**.

## 🌟 Features
- **Modern Dark UI & Glassmorphism**: Tailored color palette, radiant glowing accents, and sleek typography.
- **100% Responsive**: Fluidly optimized for mobile, tablet, laptop, and desktop viewports.
- **Direct Email Integration**: Contact form submissions are dispatched directly to `aliframadhani575@gmail.com`.
- **Interactive Capabilities**:
  - Filterable portfolio gallery with project architecture detail modal.
  - Interactive career timeline tabs (Work Experience, Education, Certifications, Community).
  - One-click CV PDF download with celebration animations.
  - Quick WhatsApp chat and copy-to-clipboard contact channels.

## 🛠️ Tech Stack
- **Frontend**: React.js 18, JSX
- **Styling**: Tailwind CSS 3, PostCSS, Custom Design Tokens
- **Icons**: Lucide React
- **Animations**: CSS Keyframes, Canvas Confetti
- **Build Tool**: Vite 6
- **Deployment**: Vercel ready (`vercel.json`)

## 🚀 Getting Started

### Installation
```bash
npm install
```

### Run Locally
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```
